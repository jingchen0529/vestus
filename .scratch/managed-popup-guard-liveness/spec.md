# 托管弹窗防护活性修复

Status: 修复完成 — 随包扩展方案实现，两轮同口径回归与四项真实门禁全绿（见 verification.md）

## 已批准目标

- 只在方舟指定同源 `/login` 及子路径限制登录交互；业务页面和弹窗正常使用。
- 首个托管 target 保留 Cookie → 完整防护就绪 → 首次导航。
- 后续弹窗只等待固定防护安装确认，订阅/页面树不挡住 resume；本地初始化有界。
- 防护/监控失败只关闭受影响 target，确认无法清理才升级全浏览器关闭。
- 明确退出登录继续销毁整个浏览器和临时托管 profile。局部故障不修改凭据。

## 测试边界（用户已批准）

1. `cdp::collect` 生产 WebSocket 流、URL report 和 managed signal：验证暂停/放行、回执、期限、局部关闭、迟到消息和去重。
2. 隔离 bundled Chromium：真实 `window.open`（异步、noopener、跨 origin、慢响应）、登录页锁定与业务交互、退出关闭。
3. watcher/桌面事件：局部失败非终止、不上报 Expired、不误提示所有页面已关闭。
4. 静态能力边界检查：固定脚本、单长期连接、首个 target 准确就绪与无越权采集。

# 帮助内容文案对齐改动说明

> **主题**：桌面端「常见问题」内容与客户交付文档 `docs/desktop-ark-auto-login-faq.md` 对齐
> **日期**：2026-11-05　**状态**：待审阅确认
> **范围**：内置模板（`app/services/desktop_faq_template.py`）、客户端内置基线（`desktop/src/assets/desktopFaqBaseline.json`）、线上库（`desktop_faq_group` / `desktop_faq_item`）三处同源内容

## 一、背景与结论

以客户交付文档为唯一准绳重建帮助内容，现为 **4 个分组、14 条问答**，分组顺序与文档一致。文档中「五、客户端提示速查」「六、什么情况需要联系管理员」「安全提醒」不是问答，未纳入结构化数据，仍保留在文档中。

对齐结果：文档 14 条 ↔ 线上 14 条，问答一一对应，**文字含义完全一致**。为适配客户端的渲染方式，另有 3 处格式/指向调整与 1 处标题格式调整，逐条列明如下，供确认。

## 二、改动记录

### 改动 1：Q9 的题号引用改为「上一条」

| 项 | 内容 |
| --- | --- |
| 位置 | 第二分组「不小心退出了方舟账号怎么办」第 4 条 ——「卡片显示红色的「登录失效」是什么意思？」 |
| 文档写法 | ……请按 **Q8** 处理：联系管理员或渠道客服，处理后点「刷新」…… |
| 线上写法 | ……请按**上一条**处理：联系管理员或渠道客服，处理后点「刷新」…… |
| 改动原因 | 客户端不显示题号。问答在客户端是折叠列表，只有问题文字，没有 Q1/Q2 编号；写「Q8」会让客户找不到对应条目，指向失效。 |

### 改动 2：Q10 的星号列表改为按行分段

| 项 | 内容 |
| --- | --- |
| 位置 | 第三分组「多个方舟账号」第 1 条 ——「我可以看到多个「方舟」入口卡片，是正常的吗？」 |
| 文档写法 | 答案后半段为 Markdown 无序列表：`* 每个账号都有自己独立的浏览器窗口和登录状态，互不影响；` 起共三条 |
| 线上写法 | 三条各自独立成行，行首不带任何符号 |
| 改动原因 | 客户端按纯文本渲染答案（仅保留换行）。`*` 不会被解析为列表圆点，会原样显示成星号。 |

### 同类处理（不单独计为一条改动）：Q6 的加粗标记

| 项 | 内容 |
| --- | --- |
| 位置 | 第二分组第 1 条 ——「我在方舟页面里不小心点了「退出登录」，怎么办？」 |
| 文档写法 | 整个过程中您`**什么都不用做**`，等窗口自己重新打开即可。 |
| 线上写法 | 整个过程中您什么都不用做，等窗口自己重新打开即可。 |
| 改动原因 | 同改动 2：纯文本渲染会把 `**` 一起显示出来。仅去掉符号，文字一字未改。 |

## 三、含义是否变化

**不变。** 三处调整只涉及两类东西：

| 调整对象 | 调整前 | 调整后 | 语义 |
| --- | --- | --- | --- |
| 条目指向（Q9） | 按 Q8 处理 | 按上一条处理 | 指向同一条问答，说法变了，客户更容易定位 |
| 列表符号（Q10） | `*` 前缀 | 换行分段 | 三个并列事项，内容与顺序不变 |
| 强调符号（Q6） | `**加粗**` | 无标记 | 强调语气由句意本身承担，文字完全相同 |

## 四、分组标题去掉「一、二、三、四」序号

| 项 | 内容 |
| --- | --- |
| 文档写法 | 一、日常使用 / 二、不小心退出了方舟账号怎么办 / 三、多个方舟账号 / 四、换电脑与配置更新 |
| 线上写法 | 日常使用 / 不小心退出了方舟账号怎么办 / 多个方舟账号 / 换电脑与配置更新 |
| 改动原因 | 客户端每个分组是**可折叠卡片**（标题 + 条数 + 展开箭头），序号属于线性文档的章节编号，不是内容。保留序号会让卡片标题显示成「一、日常使用」，与同级界面元素不一致。分组顺序由 `sort_order` 保证，与文档顺序一致。 |

## 五、可选项与建议

**可选项**：若要求与文档逐字一致，上述 4 处均可改回 —— Q9 恢复「Q8」、Q10 恢复 `* ` 列表、Q6 恢复 `**` 加粗、分组标题恢复序号。

**代价**：客户端会直接显示星号与 `**`，Q9 会出现无法定位的「Q8」，卡片标题带上章节序号。

**建议**：保持现状。文档是供人通读的线性材料，编号与 Markdown 符号在那里是有效的排版手段；客户端是折叠列表 + 纯文本渲染，两者呈现方式不同，逐字复制反而降低可用性。

如确认需要逐字一致，请回复「按文档逐字」，我将同步修改模板、客户端基线、线上库三处。

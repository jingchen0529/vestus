# Vestus desktop-v0.2.19 版本说明

## 发布信息
- 目标环境：dev 测试环境，不是生产环境。
- API 地址：`https://vestus-dev.quanyuos.com`
- 对比版本：上一成功发布版本 `desktop-v0.2.18`。
- 本版基于本地已整合提交 `5e57907`，发布说明经批准后与代码一起提交；新标签 `desktop-v0.2.19` 指向包含本说明的最终提交，不移动旧标签。
- 推送到公开仓库 `jingchen0529/vestus`，由新标签触发 Windows x86_64、macOS Apple Silicon、macOS Intel、Linux x86_64 四目标构建；全部构建成功后创建 GitHub Release。仅发布桌面安装包，不部署后端、不执行数据库迁移或回填。

## 本次更新
- 浏览器活动改为地址专用采集：记录顶层标签页地址、已脱敏的查询参数、访问次数及必要会话元数据；保留 `advid` 广告账户访问索引。不再采集点击、input/change、提交、滚动、停留时长或表单快照。
- 移除业务页面活动采集脚本、心跳、binding 与无用的 Runtime 日志订阅，减少素材页面操作的附加负载。托管固定登录防护、代理与沙箱策略保留，不默认禁用 GPU。
- 修复初始标签页、SPA、新标签页和弹窗地址采集的时序问题，排除 iframe 地址；接管前的连续 SPA 访问及其参数按顺序保留，旧 frame-tree 回执不覆盖新导航。
- 托管登录页失效检测按截止时间触发，不依赖采集心跳；优先处理已到达的跳离、关闭与断连，避免调度延迟后误报凭据失效。防护连接断开与实际登出信号仍区分处理。
- 随包浏览器由本地旧构建 `153.0.8010.12` 更新并精确锁定为 Chrome for Testing Stable `157.0.8103.78`（revision `1717349`）；从 Google 官方元数据按平台下载，不再按 Playwright 缓存修改时间挑选内核。
- 浏览器准备增加归档路径/链接、架构及实际版本校验；验证候选后再替换资源，保留旧内核备份，普通失败路径恢复原目录。
- 新活动数据省略交互字段，旧 staged 记录与 ready 批次继续按原内容和批次 ID 补报，不清空历史记录，不降低 SQLite FULL 持久性与容量回滚保障。
- 合入托管会话失效及自动登录过程的后端审计：记录失效、恢复成功和失败的固定文案及身份时间线，不记录凭据、Cookie 值或原始异常。该后端功能需要另行部署，本次桌面发布不代为部署。

## 安装与升级
- Windows x86_64：关闭旧 Vestus 及其浏览器，确认未提交的平台操作已保存后，安装 `Vestus-0.2.19-windows-x86_64.exe`；没有 Windows ARM 原生包。
- macOS Apple Silicon / Intel：分别选择 `Vestus-0.2.19-macos-aarch64.dmg` / `Vestus-0.2.19-macos-x86_64.dmg`。未签名公证，旧系统兼容性未实机验证。
- Linux x86_64：使用 `Vestus-0.2.19-linux-x86_64.deb` 或 `.AppImage`，原有重启后需重新登录的限制保留。
- 不清理用户 profile、登录存储或未确认活动队列。备份旧浏览器二进制不等于任意 profile 都可安全跨版本降级；需要回退时先隔离验证，不直接删除队列或覆盖已升级 profile。
- 不自动替换客户已经安装的旧包；本版安装包生成并验收后再分发。

## 后端配套
- 相对 `desktop-v0.2.18`，地址专用采集和内核升级不新增数据库迁移或生产上报协议；使用现有 `/api/user/browser-activity/v2` 及精确 batchId/owner/ACK 校验。
- 后端须已支持托管上报 `bootstrapSessionId` 和迁移 `0018` 以来的身份快照功能；缺少该字段兼容性的旧后端可能返回 422。dev 当前实际部署及迁移状态本次未远程核实。
- 新地址记录以零/空增量兼容现有服务端，不清零历史交互与快照。原有未确认 v2 批次重试保持原 ID/内容，不回退旧接口。
- 托管审计增强需要部署包含 `bac5ddf` 的后端代码；不新增迁移。部署、回填和生产操作需另外授权。
- 标签构建必须将实际构建 API 与本说明地址核对一致；仓库 Secret 内容未读取，本次不能仅凭 Secret 名称认定其值已匹配。不一致会由构建检查阻止。

## 验证结果
- 合并后本机两轮：桌面 Node 测试各 169 项通过、管理端各 127 项通过、后端各 491 项通过；desktop/web 构建、安全边界、Rust 格式与差异检查通过。后端有现有依赖弃用警告。
- Rust 完整回归两轮各 301 项通过、0 失败、5 项默认忽略；两个真实 CDP 忽略用例另行显式执行。其余真实持久化/跨内核升级/强杀矩阵未在合并轮执行；强杀与快速重开曾针对候选 157 两轮通过。
- 当前随包 CfT 157 的真实控制、地址采集和托管防护两轮各 2 项通过、0 失败、0 忽略，耗时 74.45 秒与 73.79 秒。测试使用 macOS ARM64、新 profile 和 localhost；采集/托管用例 headless，生命周期控制保留有窗口测试。
- 素材压力复测在新内核完成两轮：8 个组合、48 次素材区创建/清空、9600 次勾选；每次 1000 张合成卡片，视频场景 24 个小预览均可播放。未观察到冻结或大于 50ms 的长任务，显式 GC 后 DOM 节点回到 11；此结果不代表第三方真实素材页面或高分辨率视频没有内存/GPU 问题。
- 准备脚本离线测试最终两轮各 12 项通过，覆盖四平台选择、导入无副作用、错误元数据/架构/布局/ZIP 扩展字段/链接拒绝和普通失败回滚；本机官方归档与安装后的版本/架构校验通过。
- 本次 `0.2.19` 远端四平台构建、安装包安装以及客户 Windows 素材选择场景均未验证；不得将现有本地结果写成远端发布成功。实际结果以本标签构建和安装验收为准。

## 已知限制
- 本版减少客户端附加负载并升级内核，但客户素材页卡死的最终根因尚未确诊，不能承诺升级即消除所有卡顿。Windows GPU/驱动、原生内存、真实素材与网络链路仍未验证。
- Windows 真实持久化门禁仍沿用现有非阻塞策略：失败可继续构建，必须检查测试日志；发布成功不能据此宣称 Windows 持久化验收通过。分发客户前应由开发/QA 在受控 Windows 环境验证确切候选包，不把首次验收交给客户。
- 首次 frame-tree 返回前最多暂存 64 条 SPA 地址候选，超限移除最早候选并输出一次诊断，极端情况下可能漏记；持续就绪的 CDP 事件可能推迟登录截止时间通知，异常事件洪泛未增加限流。
- 已加载的初始托管文档在 bootstrap 导航与 guard 安装之间的继承时序风险未扩大修改。新 target/弹窗放行前防护验证不等于该初始阶段全部覆盖。
- 旧队列可能继续补报此前已采集的历史交互与脱敏快照；新记录稀疏格式在降级到旧桌面客户端时可能暂时不能消费，重新升级可继续补报，不能清库掩盖失败。
- 准备脚本的普通异常可回滚；恢复操作本身失败或进程在两次 rename 之间被强杀的恢复路径未完整验证。旧二进制备份不保证 profile 任意降级兼容。
- 本次使用 dev API，不面向生产。四平台原生内核实际运行只有 macOS ARM64 在本机验证，Windows/Linux/macOS Intel 以远端构建和后续安装结果为准。

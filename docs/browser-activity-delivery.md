# 浏览行为日志可靠投递与更新兼容

## 投递行为

CDP 事件送到客户端后，先写入应用本地数据目录下的 `activity-outbox/queue.sqlite3`。队列按服务器、客户端账号 ID 和 profileKey 隔离，不保存登录 token。SQLite 随客户端打包，客户无需安装数据库。

后台通常每 30 秒取队列，把同一浏览器会话的事件聚合并转成不可变 v2 批次。转批和删除暂存事件在同一 SQLite 事务中完成，意外退出不会造成一边已删、一边未保存。每批有独立随机 `batchId`；失败重试保留原 ID、原内容和采集时的客户端版本，不把新事件混入未确认批次。

服务端在同一事务中保存去重收据、累计会话和页面数据，返回包含对应 `batchId`、`protocolVersion: 2`、`acknowledged: true` 的确认。重复批次不重复累计，同一 ID 携带不同内容返回 409。新旧上报都参与写入互斥，避免并发丢失增量。

切账号时，后台只补报当前登录账号的队列。取 token 时再次在同一把锁下校验账号与 profileKey。旧账号的队列保留，待它重新登录并完成配置同步后补报；不能借用新账号的 token。客户端启动后即启动后台补报任务，无需再次打开平台。

## 分批更新顺序

推荐先升级数据库与服务端，再逐步升级客户端：

1. 备份数据库，在正常部署流程中执行 `alembic upgrade head`。本次增量迁移为 `0007`，只增加 `browser_activity_receipt`，保留历史活动数据。
2. 部署同时支持旧接口和 v2 接口的服务端。
3. 客户端逐步升级，核对活动上报和本地错误诊断。

| 客户端 | 服务端 | 行为 |
| --- | --- | --- |
| 旧版 | 新版 | 继续使用原接口和原格式；旧客户端自身仍没有可靠离线队列或批次去重 |
| 新版 | 新版 | 持久队列、账号隔离、v2 幂等投递 |
| 新版 | 旧版 | v2 返回 404，批次保留并退避重试；不回退到旧接口，避免已提交请求被重复累计 |

v2 地址为 `/api/user/browser-activity/v2`，旧地址 `/api/user/browser-activity` 保持可用。新客户端不会因后台接口暂不可用而退出账号，浏览器也可以继续使用。

服务端代码回滚时应保留 `0007` 的收据表；在仍有 v2 客户端或未确认批次时，不要删除收据或执行该迁移的 downgrade。否则日后重试可能再次累计。收据的清理需要与所有客户端的最大补报期限共同设计，目前不自动清理。

v2 收据的 `payload_hash` 是服务端对 **Pydantic 校验、默认值补全和脱敏后的内容** 按固定 JSON 规则计算的 SHA-256，并非原始 HTTP 字节的摘要。未来增加字段或默认值、修改 URL/参数/快照的规范化规则、调整序列化方式时，必须保持既有 v2 规范化结果稳定，或另开协议版本并保留原 v2 解析与摘要路径。否则客户升级或服务端回滚后，未确认批次即使原样重发，也可能因摘要变化收到 409 并阻塞补报。不能通过删除收据或给原批次重新生成 ID 来解决；协议演进测试应包含“旧服务端已提交但确认丢失，新服务端收到原批次重试”的场景。

本地队列格式有 `user_version`。不认识的版本会拒绝读写并保留原文件，不会自动删库重建。未来修改暂存载荷或协议字段时，必须设计队列迁移/协议版本兼容，不能仅修改结构体后沿用原格式版本。降级到本次改动以前的客户端会暂时停止消费新队列，重新升级后仍可补报原账号的数据。

本次不修改客户端更新策略，也不更新随包 Chromium 版本。跨平台测试在开发/CI 的测试环境运行，不会给客户机器安装或升级浏览器。

## 持久化边界与诊断

- 已提交本地队列的数据可跨断网、正常退出和进程崩溃保留。尚在网页内、CDP 通道内或尚未完成本地提交的事件，强杀/断电时仍可能丢失；这不是完整操作录像。
- 新事件入队时，暂存与待发记录合计限额为 10,000 条、128 MiB 载荷。已有记录转批可使用有界额外空间，避免满队列因计数/停留时间拆分而无法发送：单次最多转换 500 条来源，输出条数不超过来源的 8 倍，字节不超过来源的 8 倍加每条 1 KiB 元数据余量。同一账号已有待发批次时先发送，不继续转批；不同账号可独立转批。极端情况下队列不超过 80,000 条、1 GiB 加约 9.8 MiB 元数据载荷（不含 SQLite 文件开销），超过正常入队限额期间拒绝新增事件，已存记录仍可补发并释放空间。满额或磁盘不可写时保留原队列，拒绝新写入并输出诊断，不能承诺无限离线保留。诊断包括 `activity queue unavailable`、`activity observation could not be persisted`、`activity delivery deferred`。
- 收到 404、网络错误、服务端错误、缺失/不匹配 ACK 时，不删除待发批次。持续错误需修复服务端或部署兼容版本，不能通过清队列掩盖。
- 不在本次范围：CDP 断线重连、超长期离线记录的时间归属策略、逐事件历史回放。服务端既有时间校验会对超出 7 天过去/5 分钟未来的时间戳做保护处理。
- 本机账号隔离不等于操作系统用户隔离。队列只存现有采集边界允许的地址、计数、参数和脱敏快照；需要硬隔离时使用独立系统账号。

# Vestus 桌面客户端使用手册

> 本文档面向桌面端用户（客户）。文档中的产品名称以贵司实际部署时显示的名称为准（下文统称“客户端”）。
> 客户端由后台管理员统一开通与分配，使用中如遇到无法解决的问题，请及时联系管理员。

***

## 1. 认识客户端

客户端是您日常登录业务平台（以下简称「平台」）的入口。它的核心特点：

* **专属代理浏览**：打开平台时，网络请求自动走管理员为您分配的专属代理线路，避免业务环境访问差异。

* **隔离的独立浏览器**：客户端内置独立浏览器内核，与您电脑上日常使用的 Chrome、Edge 等完全隔离，互不影响登录状态和浏览记录。

* **每次打开都是全新环境**：每次点击平台都会开启一个全新的临时浏览器环境，关闭后自动清理，**不会保存 Cookie 和历史记录**，登录状态不会被复用。

也就是说：登录平台、办理业务的账号密码，请每次在打开的浏览器窗口中正常输入即可。

## 2. 安装与首次启动

客户端安装包由管理员提供，按您的操作系统选择对应安装包：

| 操作系统    | 安装包类型                |
| ------- | -------------------- |
| Windows | `.exe` 安装程序          |
| macOS   | `.dmg` 安装包           |
| Linux   | `.deb` 或 `.AppImage` |

**Windows 用户注意**：安装时建议保留默认安装位置。若要改到别的盘，请装进一个子目录（例如 `D:\Program Files\Vestus`），不要直接装在盘的根目录下（例如 `D:\Vestus`）——那样内置浏览器可能拿不到必要的系统权限，表现为打开平台后长时间白屏。参见 Q8。

**macOS 用户注意**：如果首次打开提示无法验证开发者，请右键点击客户端图标，选择「打开」，再点击「打开」即可正常启动。

启动后，客户端会停留在登录界面，等待您输入账号。

## 3. 登录系统

登录账号和初始密码由管理员统一分配，请向管理员索要。

1. 打开客户端，在登录界面输入**登录账号**和**登录密码**；
2. 点击「立即登录系统」；
3. 登录成功后进入主界面。

> 密码输入框右侧有「小眼睛」按钮，可一键显示/隐藏密码，方便核对。

**登录不成功时，常见原因：**

* 账号或密码输入错误（注意区分大小写及全角/半角符号）；

* 账号尚未开通或已被停用、过期；

* 密码刚被管理员重置，需要先修改临时密码（见下一节）；

* 电脑网络无法连接服务器，请联系管理员确认。

## 4. 修改临时密码（重要）

当管理员为您重置密码后，下发的初始密码为**临时密码**。首次使用请先修改：

1. 使用临时密码登录；
2. 按界面提示进入「修改临时密码」页面；
3. 依次输入**当前临时密码**、**新密码**（至少 6 个字符）、**再次输入新密码**；
4. 点击「修改密码并重新登录」，之后使用新密码登录。

> 修改临时密码后配置才会正常下发；修改前可能无法看到平台入口或无法正常同步配置，这是正常现象。

## 5. 主界面介绍

登录成功后进入主界面，左侧为导航栏：

* **平台管理**：默认页，展示管理员为您开放的平台入口，日常使用从这里进入；

* **系统配置**：查看代理环境状态、调整界面外观；

* 侧边栏底部显示当前登录用户信息，以及**切换主题**、**退出登录**按钮。

## 6. 使用平台（日常操作）

1. 在「平台管理」页点击管理员分配的平台入口卡片；
2. 客户端会自动为您开启一个全新的独立浏览器窗口，并直接打开该平台；
3. 在浏览器窗口中正常登录、办理业务即可。

**使用小贴士：**

* **可以同时打开多个平台**：每个平台入口互不影响，可并行操作；

* **同一平台也可以重复打开**：再次点击同一入口，会再开一个独立窗口（例如需要同时登录两个账号时）；

* **浏览器窗口是临时的**：关闭窗口后本次环境即被清理，下次打开不会自动登录、也没有历史记录，属于正常设计，请勿担心；

* 若页面提示「浏览器环境尚未就绪」或按钮无法点击，说明代理环境正在准备或出现异常，请稍后重试，或点击「重新加载」。

## 7. 系统配置

点击左侧「系统配置」进入设置页。

### 7.1 专属代理环境

此区域展示您的代理线路状态，包含三项信息：

| 状态项               | 说明                                                      |
| ----------------- | ------------------------------------------------------- |
| 网络模式              | **系统专属代理**：默认模式，访问平台走专属代理线路；**当前用户网络**：本机直连模式（需手动切换，见下） |
| 代理节点 IP / 当前本机 IP | 当前实际使用的网络出口 IP 地址                                       |
| 连接状态              | 代理已连接 / 浏览器运行中 / 正在测试 / 代理异常 / 未就绪                      |

**代理开关：** 开启时访问平台走专属代理；关闭后切换为「直连模式」，平台将直接使用您电脑当前的网络访问（一般无需关闭，仅按管理员要求操作）。

**直连域名提示：** 部分域名按管理员配置不经过代理，直连时会使用电脑的真实出口 IP；客户端会在平台列表上方明确提示这些域名，请您留意。

**重新同步配置：** 当管理员为您调整了平台权限、代理或直连域名后，客户端可能需要点击「重新同步配置」按钮来获取最新设置。若管理员更新了配置，客户端也会自动提示您重新同步。

### 7.2 外观主题

* **主题主色**：可在多种颜色中选择您喜欢的界面主色调；

* **显示模式**：明亮 / 暗黑 / 跟随系统（选择「跟随系统」时，自动匹配电脑系统的深浅色模式）。

## 8. 退出与账号安全

* **退出登录**：点击侧边栏底部的退出按钮；退出后代理和已打开的浏览器窗口会一并关闭。

* **会话失效**：如登录状态失效，客户端会自动退出并提示重新登录，请按要求重新登录即可。

* **安全提醒**：

  * 请勿与他人共享账号或密码；

  * 客户端内置浏览器为临时环境，重要信息请在业务系统内妥善保存；

  * 若电脑或网络环境发生变动后无法登录，请及时联系管理员。

## 9. 常见问题（FAQ）

**Q1：登录提示「登录失败」怎么办？**
先核对账号密码是否有误；仍无法解决请联系管理员，确认账号状态与密码是否需要重置。

**Q2：登录后看不到任何平台入口？**
说明管理员尚未为您分配平台入口，或配置尚未同步成功。请联系管理员确认分配情况，然后点击「重新加载」。

**Q3：提示「管理员已更新桌面配置，请重新同步后继续使用」？**
管理员刚为您调整了配置。请点击「重新同步配置」获取最新配置后再使用。

**Q4：点击平台没有反应，或提示「代理异常」「浏览器环境尚未就绪」？**
说明代理线路或浏览器环境暂不可用。请稍后重试；如持续异常，请联系管理员检查代理线路。

**Q5：为什么每次打开平台都要重新登录？**
客户端采用全新临时浏览器环境，按设计不保存登录状态，属于正常现象，请每次正常登录。

**Q6：打开的浏览器窗口不小心关了，数据会丢吗？**
临时环境关闭即清理。业务数据均在平台服务器上，重新打开平台登录即可，不会丢失业务数据。

**Q7：换了新电脑，还能用吗？**
可以。使用同一账号在新电脑上安装客户端并登录即可，权限与配置由管理员统一管理。

**Q8（Windows）：点击平台后浏览器窗口打开了，但长时间白屏，最后停在一个没有标题、地址栏也是空的空白页？**
这不是网络或代理问题，而是内置浏览器缺少 Windows 沙箱所需的文件访问权限，导致它的网络组件无法启动，网页始终打不开。常见于把客户端装在磁盘根目录（例如 `D:\Vestus`）的情况。

按顺序尝试：

1. 升级到最新版客户端。新版在安装和每次启动时都会自动补齐这项权限，多数情况下升级即可解决。

2. 若升级后仍然白屏，请卸载并重新安装，安装时保留默认位置，或选择一个子目录（例如 `D:\Program Files\Vestus`）。

3. 若不便重装，可请管理员以管理员身份运行命令提示符，执行下面这行（把路径换成实际安装目录）：

   ```
   icacls "D:\Vestus\chromium" /grant "*S-1-15-2-2:(OI)(CI)RX" /T /C
   ```

清理缓存、更换代理、修改 DNS 对这个问题没有帮助。

## 10. 需要联系管理员的场景

* 索要或找回账号、重置密码；

* 平台入口缺失、需要开通新平台权限；

* 代理线路异常、连接状态持续显示异常；

* 更换电脑或网络环境后无法正常使用。
